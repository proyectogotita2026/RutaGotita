# 🎨 Guía de Assets para Estación 4: "La Gotita Generosa"

Para lograr la mejor experiencia visual en la dinámica interactiva de adivinanzas, se recomienda proporcionar los siguientes archivos en la carpeta `src/assets/images/riddles/` (o `src/assets/images/`):

## 1. Ilustraciones de Respuesta (6 Adivinanzas)
- Formato: **PNG transparente con canal alfa real** (sin patrón de cuadritos "checkerboard" horneado) o **WebP**.
- Resolución recomendada: **512×512 px** (mínimo 256×256 px).
- Estilo: Acuarela pastel / ilustración kawaii infantil con trazos cálidos coherentes con Canva:

| Archivo | Representación | Paleta Sugerida |
| :--- | :--- | :--- |
| `bebe.png` | Bebé prematuro abrigado en cunita o manta lila | Crema, lila pastel, rosa suave |
| `manos.png` | Manos limpiándose con espuma y gotas de agua | Celeste agua, blanco, menta |
| `banco.png` | Fachada amigable o logo del Banco de Leche HUDN | Azul HUDN suave, crema, lila |
| `donante.png` | Mamá donante con capa tierna de superheroína | Rosa fucsia suave, lila, dorado |
| `perfume.png` | Frasco elegante de perfume con sutil prohibido/alerta | Rosa, ámbar translúcido |
| `mascotas.png` | Perrito/gatito simpático saludando desde fuera | Caramelo, blanco, lila |

## 2. Ilustraciones de la Mascota
| Archivo | Expresión / Pose | Uso |
| :--- | :--- | :--- |
| `gotita-pensando.png` | Gotita con manito en la barbilla y signo de interrogación o corazón | Estado A: Pensando |
| `gotita-feliz.png` | Gotita sonriente celebrando con destellos y corazón | Estado B: Revelado |

> **Nota:** La aplicación cuenta con un fallback gráfico enriquecido (vectorial + camafeo suave) que funciona de forma fluida y atractiva mientras se integran estos archivos finales.
